# Pebble

Pebble is a proposed offline-first personal expense and receipt tracker built with Flutter.

## Documentation

- [Product Design & Build Specification](docs/Pebble_Design_and_Build_Specification.md)
- [UI mockups](docs/mockups/README.md)

**Status:** Design and architecture planning. No Flutter application implementation has been added yet.

Core approach: Flutter, SQLite (Drift), private receipt-image storage, and on-device text recognition with manual review of scanned fields.
